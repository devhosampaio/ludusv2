# LUDUS V2

Projeto frontend do LUDUS, desenvolvido com React, Vite, JavaScript e CSS.

## Requisitos

- Node.js
- npm

## Instalação

```bash
npm install
```

## Desenvolvimento

```bash
npm run dev
```

## Build de produção

```bash
npm run build
```

## Estrutura inicial

```
src/
├── assets/
├── components/
├── layouts/
├── pages/
├── styles/
│   └── global.css
├── App.jsx
└── main.jsx
```
